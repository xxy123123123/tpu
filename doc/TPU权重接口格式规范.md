# TPU 权重接口格式规范

本文档是 TPU 卷积引擎（`tpu_conv_engine.v`）对外权重/偏置/激活/输出数据格式的
权威规范，供权重侧（模型训练/导出）对接使用。

## 一、基本数据类型（位宽与符号）

| 数据 | 位宽 | 符号 | 范围 | 说明 |
|---|---|---|---|---|
| 权重 | 8 bit | 有符号 int8 | -128 ~ +127 | 每个输入通道 1 字节 |
| 偏置 | 32 bit | 有符号 int32 | -2^31 ~ 2^31-1 | 每个输出通道 1 个 32bit 字 |
| 激活 | 8 bit | 有符号 int8 | -128 ~ +127 | 每个输入通道 1 字节，Q1.7（gray-128） |
| 输出 | 8 bit | 有符号 int8 | -128 ~ +127（ReLU 钳 0~127） | 每个输出通道 1 字节 |
| shift | 5 bit | 无符号 | 0 ~ 31 | requant 右移量，逐层 |

## 二、并行度（决定对齐要求）

- **P = 16**：输出通道并行度。`cout` 必须是 16 的整数倍。
- **C = 8**：输入通道并行度。`cin` 必须是 8 的整数倍。
- 引擎内 `ncb_r = cin/C`、`npg_r = cout/P` 都是整数除法，不满足对齐会丢失通道。

## 三、权重写入格式

### 3.1 硬件端口

```
input [15:0] w_addr   // 地址 = p*WDEPTH + idx（WDEPTH=512）
input [63:0] w_data   // C=8 时 64bit = 8 字节，一个 beat 写 C 个输入通道
```

### 3.2 一个 beat 的字节序

`w_data` 的 8 个字节对应同一核位（k）的 8 个输入通道：

```
w_data[ 7: 0]  = 输入通道 0  的权重（int8）
w_data[15: 8]  = 输入通道 1
w_data[23:16]  = 输入通道 2
...
w_data[63:56]  = 输入通道 7
```

### 3.3 地址编码

`w_addr = p*WDEPTH + idx`，其中：
- `p`（高 16 位 / WDEPTH）：输出通道 lane 号，范围 0 ~ P-1 = 0~15。
- `idx`（低 9 位，因 WDEPTH=512 即 2^9）：`idx = cb*NK + k`。
  - `cb`：输入通道块号，范围 0 ~ (cin/C - 1)。
  - `NK`：每块核位数，3x3 卷积 = 9，1x1 卷积 = 1。
  - `k`：核位，3x3 时 0~8（行优先：k = ky*3 + kx），1x1 时恒 0。

### 3.4 完整权重布局（O_CB_K_I）

一次装载 = 一个输出通道组（P 个 lane）的全部权重。字节线性序：

```
[输出通道组 pg]          （cout/P 组，乒乓装载，组间偏移 p*WDEPTH）
  └ [lane p = 0..15]     （组内 16 个输出通道）
      └ [输入通道块 cb = 0..ncb-1]   （ncb = cin/C）
          └ [核位 k = 0..NK-1]       （3x3 时 0..8）
              └ [块内输入通道 ci = 0..C-1]   （连续 C=8 字节一个 beat）
```

等价公式：一个输出通道 co 的权重字节流 =
`for cb in 0..ncb-1: for k in 0..NK-1: for ci in 0..C-1: weight[co][cb*C+ci][ky][kx]`
（即 O_CB_K_I：输出通道 → 输入通道块(cb) → 核位(ky,kx) → 块内输入通道。合并
`idx = cb*NK + k` 后线性序为「输出通道 → idx → ci」，单块 cin=C 时退化为 O_KY_KX_I）。

### 3.5 乒乓装载（重要）

- 引擎通过 `pg_load_req` / `load_pg` / `load_bank` 三信号驱动乒乓装载。
- 计算第 `pg` 组期间会预取 `pg+1` 组（写入另一 bank），与计算重叠。
- 灌完一组后拉高一拍 `w_loaded`。
- **主机必须按 `load_pg` 指定的组号、`load_bank` 指定的物理 bank 灌权重**，
  不能自己按固定顺序灌。

## 四、偏置写入格式

- 端口：`b_addr[7:0]`（输出通道号 0 ~ cout-1）、`b_data[31:0]`（int32 有符号）。
- 每个输出通道写一个 32bit 有符号 int32。
- 硬件内部把 bias 按 P 路并排切片存（`bidx = b_addr/P` 组内偏移，`bmod = b_addr%P` lane）。

## 五、激活输入格式

- `act_data` 64bit = 同一像素的 C=8 个输入通道，字节序同权重。
- 布局 HWC：先按 `(cb, 像素)` 顺序流式喂入；像素顺序 = 行优先（oy 外、ox 内）。
- 数值：int8，Q1.7，即 `round(gray - 128)`（灰度 0~255 映射到 -128~127）。
- 若 cin 不是 8 的倍数（如灰度图 cin=1），必须补齐到 8（空通道填 0）。

## 六、输出格式

- `out_data` 128bit = 同一像素的 P=16 个输出通道，每通道 int8。
- ReLU 层输出钳到 0~127；非 ReLU 层输出 -128~127。
- 发射顺序：`pg -> oy -> ox`（输出通道组 → 输出行 → 输出列）。

## 七、逐层量化语义（requant）

每层计算：
```
acc = Σ( act_int8 × w_int8 ) + bias          # int32 累加
out = clamp( round( acc >> shift ), 0, 127 )  # ReLU 时；非 ReLU 时 clamp 到 [-128,127]
```
`shift = Fin + Fw - Fout`（输入/权重/输出小数位由模型侧定，引擎只存 shift 值）。
`cfg_shift` 5bit，范围 0~31。

## 八、配置寄存器（通过 tpu_mmio，0x1000_5000）

| 偏移 | 含义 |
|---|---|
| 0x0C | {h[15:0], w[15:0]} |
| 0x10 | {cin[15:0], cout[15:0]} |
| 0x14 | bit[1:0]=stride bit[2]=pad bit[3]=ksize bit[4]=relu bit[12:8]=shift |
| 0x18 | 权重字（连续写 ceil(C/4)=2 次组成一个 64bit beat） |
| 0x1C | 权重 beat 地址（= p*WDEPTH + idx） |
| 0x20 | bias 值（32bit 有符号） |
| 0x24 | bias 地址（输出通道号） |
| 0x28 | 激活字（连续写 2 次组成一个 beat） |
| 0x2C | 输出字（连续读 ceil(P/4)=4 次取完一个 beat） |

## 九、一句话总结（给权重侧）

> 权重是 **int8 有符号**，每 8 个输入通道一组（64bit）写一次；布局按
> **输出通道 → 输入通道块(cb) → 核位(k) → 块内输入通道** 排列（O_CB_K_I，单块时即
> O_KY_KX_I）；`cout` 必须是 16 的倍数、
> `cin` 必须是 8 的倍数；偏置是 **int32 有符号**，逐输出通道一个；每层一个
> **shift**（5bit 无符号）做 requant；激活也是 **int8 有符号**（gray-128）。
